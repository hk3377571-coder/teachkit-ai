# Frontend — AI Teaching Studio

Built with Lovable (React-based no-code frontend builder).

## Pages
- Home — input form (subject, grade, topic, duration, objectives)
- Lesson Output — displays full lesson kit
- Library — saved lessons, searchable and re-editable

## Tech Used
- Lovable (Frontend builder)
- Supabase (Database connection)
- Tailwind CSS (Styling)

## Live Site
https://teachkit-ai.lovable.app/lessons
