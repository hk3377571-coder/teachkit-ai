# AI Teaching Studio 🎓

A web app that generates complete lesson kits (plan + worksheet + quiz + answer key) on demand for any topic.

## 🚀 Problem
Teachers, tutors, and trainers spend hours preparing each class — lesson plans, worksheets, quizzes, grading rubrics. AI Teaching Studio does the heavy lifting so educators can focus on teaching.

## ✨ Core Features
- Input form: Subject + Grade + Topic + Duration + Objectives + Language
- Lesson Plan: warm-up, concepts, activity, recap, homework
- Worksheet generator with answer key (multiple difficulty levels)
- Quiz generator: MCQs + short answers with auto-grading rubric
- Saved lesson library — view, edit, regenerate sections
- Multi-language output (English / Hindi / Regional)
